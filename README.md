## How I think about AI products

- **모델보다 의사결정에서 시작합니다.** AI는 사용자의 실제 업무 흐름을 개선할 때 의미가 있다고 생각합니다.
- **근거를 확인할 수 있어야 합니다.** 사용자는 AI의 답변이 어떤 데이터와 문서를 기반으로 만들어졌는지 이해할 수 있어야 합니다.
- **평가도 제품의 일부라고 생각합니다.** 검색, 생성, 사용자 가치를 각각 구분해 검증할 수 있어야 합니다.
- **실패를 전제로 설계합니다.** 로깅, 검증, 예외 처리, 권한 관리, 모니터링은 처음부터 제품에 포함되어야 합니다.
- **역할과 기여 범위를 정확하게 표현합니다.** 직접 개발한 것과 관리하거나 지원한 것을 구분하고, 경험을 과장하지 않는 것을 중요하게 생각합니다.
